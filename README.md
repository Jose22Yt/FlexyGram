## Desarrollo

La rama activa es [`codex/flexygram-beta-glass`](https://github.com/Jose22Yt/FlexyGram/tree/codex/flexygram-beta-glass).
Las versiones y los identificadores de la aplicación se declaran en [`gradle.properties`](gradle.properties).
Consulta la [documentación](docs/README.md) para conocer la arquitectura, las funciones y el proceso de compilación.

## Empieza aquí

- **Para consultar versiones:** revisa [Releases](https://github.com/Jose22Yt/FlexyGram/releases) y la información de cada entrega. Si no hay un archivo publicado, no se ofrece una descarga desde esta portada.
- **Para desarrollar:** consulta la [guía de compilación](docs/BUILDING.md) y las [normas de contribución](CONTRIBUTING.md).
- **Para informar de un fallo:** abre una incidencia con tu versión, dispositivo y pasos para reproducirlo. Revisa antes que los adjuntos no contengan información personal.
- **Para comunicar una vulnerabilidad:** sigue la [política de seguridad](SECURITY.md); evita publicar credenciales o detalles de cuentas en una incidencia abierta.

## Proyecto y comunidad

FlexyGram está creado y dirigido por [@Lukhou23](https://t.me/Lukhou23), con el repositorio mantenido por [Jose22Yt](https://github.com/Jose22Yt). El desarrollo cuenta con asistencia de **Codex**.

Las contribuciones se revisan mediante cambios pequeños, pruebas pertinentes y descripciones que permitan reproducir el problema. La autoría y las colaboraciones se conservan en el historial del proyecto.

## Hecho sobre código abierto

FlexyGram utiliza código de **Telegram para Android** y tiene como base directa **Exteraless**, con componentes y aportaciones procedentes de **NagramX, exteraGram, Nagram, Nekogram y otros proyectos**. Gracias a sus autores y a quienes mantienen las bibliotecas y recursos que hacen posible este proyecto.

Los [créditos y avisos](CREDITS.md) detallan la procedencia, el diseño y las dependencias. El proyecto se distribuye bajo [GNU GPL v3](LICENSE); los componentes de terceros conservan sus propias licencias y avisos.
