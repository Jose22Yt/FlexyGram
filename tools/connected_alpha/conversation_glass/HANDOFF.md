# FlexyGram — Conversation header + composer respect native Telegram Liquid Glass
## Scope / original failure
User physical APK showed both **Signature conversation top header** and **compact conversation bottom composer** as solid even after enabling Telegram's own Liquid Glass. User explicitly wants the effect **only when that native Telegram setting is enabled**. No separate FlexyGram master preference or new motion/blur engine.

Independent review branch based on PR #123 `e00b33e806921017ad74ff50eb5ec88607131d9c`. Separate from PR #124 (context panel) and #125 (bubble-only Glass). Nothing is merged, signed or device-verified here.

## Implementation advanced
- Native source of truth: `LiteMode.isEnabled(LiteMode.FLAG_LIQUID_GLASS)`, plus runtime availability of native blur resources. Do not infer from dark mode, header opacity, or `FlexyComposerConfig.glass()` alone.
- Top: `ActionBar.drawSignatureNativeGlass(...)` draws **Telegram's existing blur3 drawables** (back, centered title, native right action surfaces) inside the approved Signature coordinates; Adaptive, Fusion and Portrait layouts retain their original native text/avatar/buttons, geometry and hit targets. `SignatureChatHeader.draw()` picks host Glass only when ready, else returns to the existing solid `HeaderSurface` and Fusion renderer. No new bitmap, shader/capture or individual animation driver.
- Bottom: `ChatActivityEnterView.drawBackground()` skips the previously opaque **full-width** background and shadow ONLY in settled compact mode when `FLAG_LIQUID_GLASS`, hardware acceleration, `SharedConfig.chatBlurEnabled()` and `sizeNotifierLayout` all allow native rendering. The same native `sizeNotifierLayout.drawBlurRect(...)` draws within existing rounded paths for: attachment circle, middle text pill, settled send circle, or microphone circle. **One union Path clips all four independent shapes and one single native `drawBlurRect()` pass paints their shared bounding rect per parent frame** (rather than four separate native blur draws). It uses one retained Path/Rect/RectF/Paint per parent and a modest theme RGB translucent tint; no blur snapshots, per-message textures or frame allocations. Existing native send/record/attach gestures remain untouched.
- Unsupported/disabled, classic composer, recording, caption editing, top panels, animations, unavailable blur or low capability: original native/full-width background and standard hit targets are preserved.
- The old independent FlexyComposerConfig.glass setting still exists and remains respected in legacy OFF presentation; it is **not** interpreted as native Liquid Glass and does not turn on blur against the native LiteMode flag.
- Pure tint policy/source contracts and a scoped GitHub workflow were added; **no full Android Gradle compilation or phone performance proof**.
