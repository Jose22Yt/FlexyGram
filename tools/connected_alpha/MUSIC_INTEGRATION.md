## Implementation and performance boundaries

PlayerSheet uses a native scroll container for short screens/large fonts. The actual PlayerLayout bounds shrink art first (72% content width maximum, 96dp minimum), keep titles legible and permit vertical scrolling. Main controls retain all five original callbacks: three fixed circular primary controls and a separate shuffle/repeat row. Four secondary actions are speed, lyrics, queue and existing full menu; that menu also offers explicit stop. Alpha uses cached immutable Pearl/Midnight colors, a thin contour and no cover palette extraction. No new playback engine, blur, bitmap captures or navigation transition engine. Native BottomSheet transitions replace the optional mini snapshot morph only for Alpha.

Existing top PlayerBarView and bottom PlayerMiniView hosts are retained; DialogsActivity/MainTabsActivity and ActionBarLayout are untouched. Compress uses the chevron, music continues. Bubble is an ordinary 56dp child of the owning fragment FrameLayout; drag is clamped to available window/IME/cutout space, top/header and lower-control reserves. Tap expands to the existing mini; long-press offers expand/stop. Main mini and top bar retain separate long-press stop; full player has stop in More. Bubble has no playback observers, engine, audio focus, permission, window or preference. Its lifecycle adapter consumes the hosts' existing notification callbacks; shared state is UI-only, weak listener references are removed on detach. Unsupported non-FrameLayout hosts retain the mini and cannot compress.

The native MediaController, queue loading/order, speed, system media session, service, focus, notification and background paths are unchanged. Voice/live-location/call/import/story handlers in FragmentContextView remain exact; its additions are isolated music hosting and theme refresh. Presentation is shared across hosts, not a second copy of playback state. Artwork stays in existing ImageReceiver/PlayerArt caches; no quantization runs for Alpha. Wave/equalizer reuse Paint/Path, cap visible redraws at approximately30Hz and stop scheduling when not shown/power saver. Fixed control bounds avoid the old width spring's per-frame measure/layout. Mini show animation is cancelable180ms and canceled on detach. This is structural evidence, NOT a measured speedup.
