Glare effects extension
=======================

The existing preference OEAppearanceGlassOutlineStyle and its values remain stable:
0 = default glare, 1 = solid, 2 = hidden. Appended values 3 = double outline and
4 = adaptive. The dialog retains its existing first three entries. Backup and
restore accept the two new values. English, Spanish and Russian labels are included.

Double draws a thin white outer line and a softer black inner line. Adaptive
chooses contrasting ink and strength from the available surface color, with a
hysteresis band to avoid switching around mid-gray. Both use cached paths and
respect drawable alpha; they add no blur or independent animation.

Adaptive samples up to nine pixels of an already available CPU bitmap at most
once per 180 ms during existing draws. Wrapped/GPU sources can provide their
existing under-source; otherwise it uses the theme color. It never reads GPU
pixels or captures the screen. Static stroke helpers and standalone StrokeDrawable
use their available theme/provider colors rather than sampling the screen.

Verification: tools/glare/android/run.py compiles the production controller,
mapper, contour renderer, sampler, StrokeDrawable and extracted native static
stroke methods with explicit app/source host doubles. Its 14 native Canvas tests
cover persistence, compatibility, contrast/hysteresis, bounded sampling, unavailable
sources, double edges, alpha and borrowed Paint preservation. The default static
effect is pixel-compared with its historical implementation. This isolated probe
does not build the full app or exercise the GPU render-node pipeline on a device.
See tests/test_glare_effects.py for wiring/resource/backup checks.

No APK is generated by this change. Physical-device visual verification is pending.
