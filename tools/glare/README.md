# Glare effects

The three original choices remain: Disabled, Default and Solid outline. The
compact glare preview and Double/Adaptive are removed. The additional Outline
thickness row adjusts 0.5x..3x and defaults to the original 1x. Its existing-store
preference is OEAppearanceGlassOutlineWidth, bounded 5..30, with native backup
metadata. No restart, independent blur engine or animation loop is added.

The isolated Android fixture compiles the real mapper/controller, static stroke
methods, StrokeDrawable and width policy with explicit app/config hosts. Native
Canvas checks compare default glare pixels against the original implementation,
verify thin/thick/hidden rendering and borrowed Paint restoration, and exercise
Apply/Cancel/Reset and persisted dialog values. The real Kotlin configuration and
full GPU RenderNode pipeline are not integration-compiled by this fixture.

See docs/settings3/INPUT_BLUR_WIDTH_ASYNC.md. No APK generated by these checks.
