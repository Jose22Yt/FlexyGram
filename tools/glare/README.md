# Glare effects

Only Disabled, Default and Solid outline remain. No adjustable thickness,
width preference or preview. A fixed 1.10x contour emphasis makes the edges a
little more visible without altering blur, opacity or shadow. Hidden remains
hidden. See docs/settings3/BETA8_FIXED_GLARE.md.

The isolated Android fixture compiles the production controller, static stroke
methods, StrokeDrawable and fixed width policy with explicit app/config hosts.
Native Canvas checks compare the small change in contour coverage against the
historical renderer and verify center transparency, hidden mode and borrowed
Paint/shader restoration. It does not compile the full GPU RenderNode pipeline
or run the app on a device.
